# Sectigo eSeal procurement guide

This file explains how to procure an Advanced or Qualified eSeal from Sectigo.

## Procurement process

- Product information is available [here](https://www.sectigo.com/ssl-certificates-tls/eidas-sealing-certificates)
- For Qualified eSeal certificates, choose "Certificate for Qualified Seals". The private key will be delivered on a physical token.
- For Advanced eSeal certificates, choose "Certificate for Advanced Seals". The private key will be delivered as a file.
